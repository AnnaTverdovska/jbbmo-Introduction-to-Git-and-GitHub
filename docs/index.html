How it’s calculated

Simple interest is paid only on the amount you started with, so it grows by the same sum every year: p × r × t / 100.

Compound interest is added to the balance once a year, and the next year’s interest is calculated on that larger balance: p × (1 + r/100)t − p.

p is the amount, r the yearly rate in percent and t the number of years. The command-line versions in this repository, simple-interest.sh and compound_interest.py, use the same formulas.
